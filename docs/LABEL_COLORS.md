# Label Organization Guide

This guide provides comprehensive documentation for all labels used in the repository, organized by category for improved visual organization and consistent issue triage.

## Label Categories

| task | issue-type | A task that needs to be completed |

## Usage Guidelines

### Issue Type Labels

- **bug**: Apply to any issue describing incorrect behavior, broken functionality, or errors
- **enhancement**: Apply to suggestions for new features or improvements to existing functionality
- **feature**: Apply to implementations of new features or capabilities
- **task**: Apply to specific tasks that need to be completed as part of a larger project
- **question**: Apply when more information is needed to resolve the issue
- **wontfix**: Apply to issues that will not be addressed (for documentation purposes)

### Platform Labels

- **macOS/iOS/web**: Apply to issues that affect specific platforms
- **platform**: Apply to cross-platform compatibility issues
- **frontend/backend**: Apply to issues specific to frontend or backend codebases
- **testing**: Apply to testing infrastructure, test failures, or test coverage issues
- **hooks**: Apply to issues related to hook execution and integration
- **memory**: Apply to memory management, allocation, or optimization issues
- **context**: Apply to issues related to context management and state

### Status Labels

- **critical**: Apply to issues requiring immediate attention
- **hotfix**: Apply to urgent fixes that need rapid deployment
- **in-progress**: Apply when active work is underway
- **blocked**: Apply when work is stopped waiting on external factors
- **needs-review**: Apply when code is ready for peer review
- **needs-approval**: Apply when work requires stakeholder approval
- **wip**: Apply to work-in-progress that is not yet ready for review
- **waiting-on-decision**: Apply when awaiting architectural or design decisions
- **good-first-issue**: Apply to beginner-friendly issues
- **help-wanted**: Apply to issues where community help is needed

## Categories Overview

1. **issue-type**: Labels that define the nature of the issue
2. **platform**: Labels that identify technical domains and platforms
3. **status**: Labels that indicate the current state or priority of work

This organization ensures consistent labeling across the repository and enables efficient filtering, searching, and dashboards based on label categories.
